# Contributing to Oh Mine OpenClaw

Welcome! We love contributions! 🎉

**[🇺🇸 English](CONTRIBUTING.md)** | **[🇨 中文](CONTRIBUTING_CN.md)**

## 🇺 English Version

### How to Contribute

#### Reporting Bugs

1. Check existing issues first
2. Use the bug report template
3. Include environment info (OpenClaw version, OS, etc.)

#### Suggesting Features

1. Open an issue with "Feature Request" label
2. Describe the use case
3. Explain why it's useful

#### Pull Requests

1. Fork the repo
2. Create a branch (`git checkout -b feature/amazing`)
3. Make your changes
4. Test locally
5. Submit PR

### Development Setup

```bash
git clone https://github.com/toller892/oh-mine-openclaw.git
cd oh-mine-openclaw
npm install
openclaw plugins install .
openclaw gateway restart
```

### Code Style

- TypeScript, strict mode
- Follow existing patterns
- Add comments for complex logic

### Questions?

Open an issue or ping us on [Discord](https://discord.gg/clawd)!
